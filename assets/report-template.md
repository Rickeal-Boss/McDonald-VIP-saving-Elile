# 输出报告模板

> 由 `scripts/report.py` 按本模板渲染。**必含字段**：方案名 / 商品明细 / 实付【元】 / 省钱额【元】 / 优惠来源 / 查询时间戳 / 门店。

---

## 最省方案

- **方案名**：`〈路径 A 卡权益 / 路径 B 门店券 / 路径 C 结构改造〉`
- **商品明细**：`〈商品名 × 数量，规格〉`
- **优惠来源**：`〈麦金卡权益项 / 券名（券码后四位）/ 无〉`
- **实付金额**：`¥〈…〉`（= `calculate-price` 分 ÷ 100）
- **省钱额**：`¥〈…〉`（**分列** = 商品自身 `discount` ÷ 100 ＋ 券后省额 `enjoyed` ÷ 100；两口径不混加、不互相顶替）
- **取餐方式 / 门店**：`〈到店自取 / 麦乐送 / 得来速〉@ 〈门店名（storeCode）〉`
- **查询时间**：`〈ISO8601〉`

## 支付

- 官方支付链接：`〈仅在下单场景返回；由用户自行完成支付〉`
- **本技能为只读试算，不代下单、不代领券、不代抽奖。**

---

### 模板化提示（按命中情况附加）

- 若命中随单购：> 「已默认不勾选随单购（附加付费项）；以上为不含附加项的真实到手价。」(RL-04)
- 若卡权益不可确认：> 「无法确认您的麦金卡权益在本单是否生效，以上为两条路径各自的实测价，供您对照选择。」(L3)
- 若身份折扣冲突：> 「检测到其他身份折扣，与麦金卡不叠加，无法判断两条路径相对优劣。」(RL-17)
- 若降级到原价：> 「当前无法获取优惠试算，以上为菜单原价。」(L4)
- 若为离线 demo：> 「当前为离线样例演示，非真实 MCP 调用。」(RL-19)
- 通用脚注：> 「价格随活动/门店变动，以官方页面为准。查询时间：〈…〉。」(RL-18)
