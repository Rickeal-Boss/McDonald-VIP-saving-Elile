# L2 · 失败降级阶梯（L0–L5）

| 级别 | 触发条件 | 用户可见输出 |
|---|---|---|
| **L0 正常** | 双路径均算价成功 | 最省方案 + 候选对比表 + 支付链接 + 时间戳/门店 |
| **L1 部分降级** | 某条路径算价失败，其余成功 | 成功路径正常输出；失败路径标注"暂无法试算，原因〈…〉"，不给数字 |
| **L1' 门店不可用** | `query-meals` 报 `600057`（门店已关闭/非营业时间） | 用 `businessStatus`/`businessEndTime` 预筛，改选营业中门店（RL-22） |
| **L2 券路径失效** | `query-store-coupons` 空/失败 | "本单暂无可用门店券" + 卡路径/原价路径对照 |
| **L3 卡权益不可确认** | H2/H3 不成立或探测失败 | "无法确认您的麦金卡权益在本单是否生效" + 两路各自实测价（卡倾向项用具名"麦金卡"SKU 代表） |
| **L4 算价全面失败/429** | `calculate-price` 全失败或预算耗尽 | **降级到原价 + 明确提示**："当前无法获取优惠试算，以下为菜单原价，建议稍后重试或到官方 App 核对" |
| **L5 无法判定** | 数据缺失 / 身份折扣冲突 / 无定位 | "无法给出可靠比较：原因是〈…〉；建议〈…〉"（🔴RL-06，**禁止编造数字**） |

## 通用原则
- **不崩溃、不静默重试轰炸**：仅对 429 与瞬时错误重试（`max=2`, `base=1.5s`），业务错误不重试。
- 每一级都落 Trace `degrade` 事件，供成本画像统计失败重试率。
- 降级时**保留已获得的真实数字**，只对缺失部分明示不可得。
