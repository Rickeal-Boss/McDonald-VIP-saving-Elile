## 三条不可越过的边界（摘要）

1. **只读**：禁一切写操作（🔴RL-01）。
   > **诚实定位**：只读由 **SKILL.md 硬规则**保障；`scripts/whitelist.py` 仅为「调用前策略辅助 + 违规检测」，**非架构级强拦**（脚本无法拦截 Agent 直接发起的 MCP 调用）。
   > **代价须声明（🔴RL-24）**：只读 ⇒ 不领券（`auto-bind-coupons` 禁用）⇒ **未领取的可领券不在候选内**，实付可能被**系统性高估**，报告**必带**该声明。
2. **券候选只来自 `query-store-coupons`**（🔴RL-03）。
3. **不可判定就说不确定，不给错数字**（🔴RL-06）。

## 关键常量（速览）

- 时段：早餐 `05:00–10:29`，正餐其余。
- 金额：菜单=元，算价=分。
- 限流：600 次/分钟 → 本技能 120ms 间隔 + 串行 + 缓存。
- 算价预算：12 次/会话。
- 券**临期**阈值：`≤ 1 天`（`coupon_filter.EXPIRING_SOON_SECONDS = 86400`）→ 置顶告警。
- 门店三级兜底：`searchType=2`(city+keyword) → 收藏 → `order-list` 反推（**仅 ~10 单、无分页**）。
